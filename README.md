# blahblah

A neural networks learning project built with Google Colab. The notebook explores building neural networks from scratch, covering topics like:

- Reading and visualizing admission test score data
- Understanding AND gate logic with neural networks
- Setting weights and biases for perceptrons

## Files

- `admission.ipynb` — Main Colab notebook with neural network examples and visualizations
- `Blah.txt` — Project notes

## Getting Started

1. Open `admission.ipynb` in [Google Colab](https://colab.research.google.com/github/nestrocuation/blahblah/blob/master/admission.ipynb)
2. Run the cells to see the data visualizations and neural network examples

## Requirements

- Python 2+
- pandas
- numpy
- matplotlib
