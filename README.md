# blahblah

A neural networks learning project built with Google Colab. The notebook explores building neural networks from scratch, covering topics like:

- Reading and visualizing admission test score data
- Understanding AND gate logic with neural networks
- Setting weights and biases for perceptrons

## Color Game

A fun game for little kids! Tap a color button or press the microphone and say a color name — the whole screen fills with that color.

**To play locally:** open `color-game.html` in any browser (just double-click the file).

- 10 colors: Red, Blue, Green, Yellow, Orange, Purple, Pink, Brown, Black, White
- Voice recognition — tap the mic and say a color
- Celebration animations on every pick

## Files

- `color-game.html` — Interactive color game (open in browser)
- `admission.ipynb` — Colab notebook with neural network examples and visualizations
- `Blah.txt` — Project notes

## Getting Started

1. **Color Game** — double-click `color-game.html` to play locally in your browser
2. **Notebook** — open `admission.ipynb` in [Google Colab](https://colab.research.google.com/github/nestrocuation/blahblah/blob/master/admission.ipynb)

## Requirements
